## 0. Подготовка
- [ ] Интеграционные тесты: `cd server && VYCORD_TEST_DSN=postgres://vycord:vycord_secret@localhost:5432/postgres?sslmode=disable go test ./internal/repository/postgres/ -run 'Migration027|ListenedFor' -v` → 3 PASS
- [ ] `make migrate-up` на dev-БД; откат: `make migrate-down` → `make migrate-up` — без ошибок
- [ ] Бэкенд свежей сборки; клиент `npm run dev:vite`, запущенный после последнего коммита; плюс Electron
- [ ] Два аккаунта (А и Б) в одном канале

## 1. Кнопка микрофона
- [ ] Пустое поле → вместо «Отправить» микрофон (десктоп и мобильная ширина)
- [ ] Ввёл текст → «Отправить»; стёр → микрофон
- [ ] Прикрепил файл → «Отправить»; убрал → микрофон
- [ ] Гостевой чат (ссылка на звонок): микрофона нет, голосовые участников видны и играют

## 2. Запись удержанием (мышь в Electron, затем тач в DevTools / на телефоне)
- [ ] Удержал ~3 с → отпустил → голосовое сразу в ленте («отправляется»), затем обычное; пока грузится, его можно прослушать
- [ ] Во время удержания: таймер, красная точка, уровень, «‹ Отмена», стрелка вверх
- [ ] Короткий клик / удержание < 1 с → «Удерживайте, чтобы записать», ничего не отправлено
- [ ] Удержание → влево → отмена сразу (до отпускания), ничего не ушло, индикатор микрофона в ОС гаснет
- [ ] Удержание → вверх → закреплено, есть «Удалить» и «Отправить»; «Отправить» — ушло; «Удалить» — нет; Escape — удалено
- [ ] На телефоне свайп по микрофону не скроллит страницу, не выделяет текст, не вызывает контекстное меню
- [ ] Держу одним пальцем и касаюсь кнопки вторым → запись не прерывается и не отправляется

## 3. Прерывания и ошибки
- [ ] Во время удержания Alt+Tab → «Запись прервана», ничего не ушло
- [ ] В закреплённой записи свернул окно и вернулся → запись идёт
- [ ] Во время звонка нажал микрофон → «Нельзя записать голосовое во время звонка», звонок не затронут
- [ ] Запрет микрофона: в Electron на macOS подсказка ведёт в «Системные настройки → … → Микрофон»; в браузере — общий текст
- [ ] Нет микрофона / отключён → «Микрофон не найден»
- [ ] Выбран конкретный микрофон в настройках (VYC-99) → запись идёт с него
- [ ] (по желанию) Запись 15 минут → останавливается и отправляется сама

## 4. Клавиатура (десктоп)
- [ ] Tab до микрофона → Enter → закреплённая запись, фокус на «Удалить»
- [ ] Удерживаю Enter/Space после старта → запись **не** удаляется
- [ ] Tab до «Отправить» → Enter → отправлено
- [ ] Первая запись с клавиатуры в браузере с запросом разрешения → после «Разрешить» запись идёт, не «прервана»

## 5. Плеер голосового
- [ ] Волна-столбики, длительность в покое, текущее время при игре; нигде нет «Infinity»/«NaN»
- [ ] **Перемотка в Electron (главный риск):** клик по волне; перетаскивание; ←/→ на сфокусированной волне (±5 с)
- [ ] Скорость 1x → 1.5x → 2x → 1x; после перезагрузки скорость сохранилась
- [ ] Играет одно, запускаю другое голосовое/видео → первое на паузе; начало записи ставит играющее на паузу
- [ ] Долго открытая страница (протухшая подпись) → голосовое всё равно играет
- [ ] Обычный аудиофайл (mp3) — старый плеер с именем и скачиванием, не пузырь

## 6. «Прослушано» (два аккаунта)
- [ ] А отправил → у Б точка «не прослушано», у А тоже
- [ ] Б нажал play → у Б точка гаснет сразу, у А — **без перезагрузки**
- [ ] А слушает своё голосовое → его точка **не** гаснет
- [ ] Перезагрузка у обоих → статусы сохранились
- [ ] Б на двух устройствах: слушает на одном → точка гаснет и на втором
- [ ] У гостя точки нет

## 7. Сеть и отказы
- [ ] DevTools → Offline → записал → «не отправлено · повторить»; включил сеть → повторить → ушло ровно одно сообщение
- [ ] Записал и сразу переключил канал → в новом канале лишней строки нет, голосовое в исходном
- [ ] Упавшую строку удалил корзиной → исчезла

## 8. Сообщение-голосовое
- [ ] Нет «Редактировать» и «Цитировать» (десктоп hover и мобильное long-press меню); «Удалить» у своего есть
- [ ] Удаление голосового работает у обоих

## 9. Внешний вид
- [ ] Светлая и тёмная тема: пузырь, полоса записи, подсказка читаются
- [ ] Ширина ~375 px: полоса и пузырь не вылезают, подсказка переносится
- [ ] «Уменьшить движение» в системе → красная точка записи не пульсирует

## 10. Другие платформы (если есть)
- [ ] Safari / iOS: запись уходит, в ленте голосовое (не видео), волна не плоская
- [ ] Голосовое из Chrome/Electron играет в Safari
