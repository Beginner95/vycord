# Группировка сообщений чата по дате

Дата: 2026-08-09
Статус: черновик (ждёт утверждения)

## Цель

В ленте сообщений текстового канала группировать сообщения по календарным дням: добавлять между
группами дней визуальный разделитель с датой. Для «сегодня» и «вчера» показывать словесные метки,
для остальных дней — полную дату в формате «01 февраля 2026».

## Требования

1. Сообщения одного календарного дня (по локальному времени) образуют группу.
2. Между разными днями показывается разделитель-дата.
3. Текст метки разделителя (порядок приоритета, по локальной дате сообщения относительно
   текущей локальной даты):
   - «Сегодня»;
   - «Вчера»;
   - иначе — «01 февраля 2026» (число с ведущим нулём, склоняемый рус. месяц, год) —
     в ru-локали; в en-локали аналогично, но по-английски (например «February 1, 2026»).
4. Визуально разделитель — центрированный текст, сквозная горизонтальная линия слева и справа
   от текста (линия «сливается» за текстом).
5. Существующая «компакт»-группировка (ByTheWay: один автор в течение 7 минут) не должна
   объединять сообщения из разных дней: смена дня ломает компакт-группу.
6. Разделитель ставится и в начале ленты, и в режиме истории (historyMode).

## Не-цели (YAGNI)

- Виртуализация списка.
- Группировка по неделям/месяцам.
- Другие спец-метки, кроме «Сегодня» и «Вчера».
- Изменения в сторе/«блоках сообщений».

## Подход

Вариант А — точечное сравнение соседних сообщений внутри существующего `messages.map` в
`client/src/components/ChatArea.tsx` (строки ~668–790). Данные уже в хронологическом порядке
(`messageStore` аппендит в конец, `AppPage` заменяет массив при переключении канала), поэтому
достаточно сравнивать локальную дату текущего и предыдущего сообщения: при изменении дня выводить
разделитель перед сообщением.

## Архитектура / изменения кода

### 1. Форматирование даты — `client/src/i18n/format.ts`

Расширить хук `useDateFormat` новым методом `formatFullDate(date)`:

- Определяет «нормализованный» день (год-месяц-день по локальному времени).
- Если день = сегодня → возвращает i18n-ключ/значение «Сегодня».
- Если день = вчера → «Вчера».
- Иначе — полная дата строкой.

Для полной даты использовать ручное форматирование (Intl `toLocaleDateString` с `month:'long'`
даёт «1 февраля 2026 г.» — не подходит):

- день: `String(d.getDate()).padStart(2, '0')` → «01»;
- месяц: имя в родительном падеже из словаря (ru) / английское название (en);
- год: `d.getFullYear()`.

Словари месяца (ru, именительный/родительный) и (en) вынести в `format.ts` или `locales` — на
усмотрение реализации; главное — поддержка ru и en.

Зависимость «Сегодня/Вчера» против полной даты: решаем на момент рендера, сравнивая локальный день
даты сообщения с локальным днём `new Date()`.

### 2. Компонент разделителя — `client/src/components/ChatArea.tsx`

Вынесли (или инлайн в цикле) отрисовку `<DayDivider label={...} />`.

Логика в цикле `messages.map`:

```
const prevMsg = messages[idx - 1];
const dayChanged =
  !prevMsg ||
  startOfDay(msg.created_at) !== startOfDay(prevMsg.created_at);
```

При `dayChanged` перед сообщением возвращаем `<Fragment>`:
`<DayDivider label={formatFullDate(new Date(msg.created_at))} />` + само сообщение.

Чтобы компакт-группа не «склеивала» разные дни, дополнить условие `isCompact` требованием
`!dayChanged` (или вычислить `dayChanged` до `isCompact` и учесть).

Метод `formatFullDate` добавить в деструктуризацию `useDateFormat()` на строке ~143.

### 3. Локализация — `client/src/i18n/locales/ru.ts` и `en.ts`

Добавить ключи: `chat.today`, `chat.yesterday` со значениями «Сегодня» / «Вчера» (и en-эквиваленты).

### 4. Стили — `client/src/components/ChatArea.css`

Класс для разделителя, например `.date-divider`:

- контейнер: `display:flex; align-items:center; justify-content:center; gap:12px;` (или line-based);
- текст: цвет из CSS-переменных темы, фон (прозрачный паддинг), чтобы линия визуально проходила
  за текстом;
- линия: два псевдоэлемента/элемента `::before` и `::after` — `flex:1`, `height:1px`,
  `background: <mutedBorder>`, по одному с каждой стороны текста.

### 5. Поведение при новых сообщениях / истории

- Новые входящие сообщения (`addMessage`) аппендятся — при смене дня разделитель появится сам
  (логика в `map`).
- `historyMode`/`getMessagesAround` заменяют массив — разделители пересчитываются из нового набора
  автоматически.

## Обработка ошибок / крайние случаи

- Пустая лента: разделитель не выводится (рендер-ветка «канал пуст» уже есть).
- `created_at` всегда валидна (сервер генерирует ISO). Доп. защита не требуется.
- «Сегодня/Вчера» определяются по локальному времени — корректно для локальных пользователей.

## Тестирование

В проекте нет тестового фреймворка для компонентов (React без тестов). Поэтому проверка — ручная:

1. Отправить сообщения в разные дни (симуляция через `created_at` или реальные) — разделители
   появляются между группами.
2. Проверить метки «Сегодня»/«Вчера» для соответствующих сообщений.
3. Проверить ru и en локали.
4. Проверить, что компакт-группы не пересекают границу дня.
5. Проверить историю / jump-to-message — разделители корректны.
6. `npm` сборка/линт без ошибок.

Через какой инструмент гонять линт/типы/сборку — уточнить по `client/package.json` при реализации.
